作品集 · 观看说明
=========================================================

一、怎么打开
    1. 把整个压缩包解压（不要只解压 index.html，素材都在子文件夹里）
    2. 双击 index.html
    3. 用 Chrome / Edge / Safari 打开即可（推荐 Chrome）

    不需要联网，不需要安装任何软件。

二、怎么看
    页面顶部四个大色块＝四个大类，点一下切换。
    下面一排小圆角标签＝细分小类，点一下只看这一类。
    点任意图片或视频卡片 → 放大播放。
    视频播放时可用键盘 ← → 切换上一条/下一条，Esc 关闭。

三、内容构成
    111 条素材：67 条视频 + 44 张图片
    4 个大类 · 26 个细分小类

        01 海外视频素材   28 条   尼日利亚 / 泰国 / 乌干达 / 巴西
        02 海外图片素材   42 张   大字报 / 卖点罗列 / 表单类 / 通用界面
        03 国内短视频     36 条   口播 / 好物分享 / vlog / 信息流 / 活动等
        04 长视频          5 条   访谈 / 课程 / IP 跟拍 / 封面设计

四、关于画质
    为方便传输，视频已压缩为 720p（长边）H.264 格式，
    原始文件为 4K，需要高清版本可单独索取。
    单条视频仍在 1–4MB 之间，弱网也能流畅播放。

五、常见问题
    Q：打开发现图片不显示？
    A：多半是只解压了 index.html。请把整个压缩包完整解压。

    Q：视频点开没声音 / 放不了？
    A：换 Chrome 打开。Safari 对本地文件权限较严。

    Q：页面上还能改内容吗？
    A：不能，这是导出的只读版本。
